# Status Tracking

**Purpose** — give everyone a single, accurate view of what work exists and where it
stands. Consistent statuses let anyone read the state of the work without asking.

**When it applies** — to all work.

**Roles** — the **developer** keeps their items in Linear up to date and sets the
correct status.

## Track all work in Linear

All work is tracked in **Linear**. If a piece of work isn't captured as a Linear
item, it isn't tracked — create the item so its status is visible to the team.

## Statuses

Each item carries exactly one of the following statuses:

- **Backlog** — Work that is being planned but does not yet meet the
  [Definition of Ready](definition-of-ready-for-code.md), or has not been scheduled to
  begin work soon.
- **To Do** — This item is known but not yet started.
- **Blocked** — The item is actively blocked by something outside of your control. If
  the issue is within your control, it is not Blocked — either keep working it
  (In Progress) or, if you've set it aside, mark it Paused. An item should not be
  paused unless a priority change has been approved. List any block(s) in the item
  details and who owns getting it unblocked.
- **Paused** — This item was begun but is not currently being worked on. This may
  happen due to a priority change or unplanned work. If the item is blocked by
  something outside of your control, use the Blocked status instead.
- **In Progress** — This item is actively being worked on and there are no known
  blockers stopping progress. If there are expected blockers coming up that are not
  currently blocking progress, the item is In Progress and the expected blockers
  should be listed in the item details.
- **In Review** — The developer believes the work is done and is waiting for **manual
  review** — review and approval by the requester. List who is reviewing it in the item
  details.
- **Done** — The item is completed and fully meets our
  [Definition of Done for Code](definition-of-done-for-code.md). Over time we will
  refine our definition of done.
- **Archived** — Work that has been done and we no longer want to show on our
  Linear dashboard.
- **Cancelled** — Work that will not be done. It was decided the item is no longer
  wanted, so no further effort will be spent on it.
- **Duplicate** — This item duplicates another item and will not be worked on its own.
  Link to the item it duplicates in the details, and continue the work there.
